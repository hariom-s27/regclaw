Reason: installed `litellm` pre-call hooks are `[Non-Blocking]` (swallowing cap exceptions), `mock_response` skips HTTP dispatch, and sync success callbacks run asynchronously on background threads (`BoundedLoggingThreadPoolExecutor`) with non-blocking error swallowing.
